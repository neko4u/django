# 前端主题规范（THEME）

> 本文件是**项目标准**。所有子页面/新模块的配色、间距、圆角、阴影一律以本文档为准，
> 令牌的唯一实现是 `static/css/theme.css`。引入顺序见文末「接入方式」。

---

## 1. 主色

全站**只有一个主色**：蓝色 `#2b7de9`。

| 用途 | 变量 | 值 |
|---|---|---|
| 主色（按钮、链接、强调数字） | `--accent` | `#2b7de9` |
| 主色·悬停 | `--accent-hover` | `#1a6ad4` |
| 主色·按下 | `--accent-active` | `#155dc0` |
| 主色·浅底（选中态、徽标、角标） | `--accent-light` | `#e8f1fe` |
| 主色·描边 | `--accent-line` | `#b9d4fb` |

**原则**：主色只用来标记「可点击 / 当前选中 / 需要强调的数字」。
不要用它做大面积背景（面积超过 15% 就改用 `--accent-light`）。

## 2. 背景三级（深浅交错的基础）

| 层级 | 变量 | 值 | 用在哪 |
|---|---|---|---|
| 内容面 | `--bg-primary` | `#ffffff` | 卡片、输入框聚焦后、抽屉、浮层 |
| 导航面 | `--bg-secondary` | `#f5f8ff` | 页面底色、侧边栏、输入框默认 |
| 强调面 | `--bg-tertiary` | `#e8f0fe` | 问题气泡、表头、hover、代码底色 |

**交错规则**（照这个来就有层次，不用另想）：

```
页面底 = --bg-secondary
  ├─ 侧栏 / 顶栏 = --bg-secondary 或 --bg-primary（两者之间必须有 1px 边框隔开）
  └─ 主内容 = --bg-primary
        └─ 主内容里的强调块 = --bg-tertiary
              └─ 浮层/抽屉 = --bg-primary + --shadow-md
```

**禁止**：相邻两层用同一个颜色且不加边框 —— 会糊成一片。

## 3. 文字三级

| 层级 | 变量 | 值 | 用在哪 |
|---|---|---|---|
| 主文字 | `--text-primary` | `#1a1a2e` | 正文、标题 |
| 次文字 | `--text-secondary` | `#5f6b7a` | 说明、副标题、按钮次要文字 |
| 弱文字 | `--text-muted` | `#a0afc2` | 时间、计数、占位符、禁用 |

正文最小 `14px`，行高 `1.75~1.8`；次要信息 `12~13px`。

## 4. 线条

| 变量 | 值 | 用在哪 |
|---|---|---|
| `--border` | `#d0d7e2` | 输入框、实心按钮的描边、明显分割 |
| `--border-soft` | `#e6ecf5` | 卡片描边、顶栏/侧栏分割线（默认用这个） |

## 5. 语义色

| 变量 | 值 | 用途 |
|---|---|---|
| `--danger` | `#e5534b` | 错误、删除 |
| `--danger-soft` | `#ffe3e3` | 错误提示底色 |
| `--success` | `#2f9e63` | 成功、正向反馈 |
| `--warning` | `#d9822b` | 警告、缺数据提示 |

语义色**只表达状态**，不做装饰。

## 6. 阴影两级

| 变量 | 值 | 用在哪 |
|---|---|---|
| `--shadow-sm` | `0 1px 3px rgba(26,42,78,.06)` | 静态卡片 |
| `--shadow-md` | `0 8px 24px rgba(26,42,78,.12)` | 浮层、抽屉、tooltip |

不要用纯黑阴影，统一带一点蓝调（`26,42,78`）。

## 7. 圆角

| 变量 | 值 | 用在哪 |
|---|---|---|
| `--r-sm` | `6px` | 角标、小图片、代码块内元素 |
| `--r-md` | `10px` | 按钮、输入框、卡片 |
| `--r-lg` | `14px` | 气泡、浮层、抽屉 |
| `--r-pill` | `999px` | 徽标、标签、示例问题按钮 |

## 8. 间距

`--s1..--s8` = `4 / 8 / 12 / 16 / 20 / 24 / 32`，**只用 4 的倍数**。
组件内边距常用 `--s3`；区块之间 `--s4 ~ --s6`。

## 9. 尺寸

| 变量 | 值 |
|---|---|
| `--topbar-h` | `56px` |
| `--sidebar-w` | `260px` |

## 10. 组件写法约定

| 组件 | 规则 |
|---|---|
| 主按钮 | `.t-btn`（主色底、白字、`--shadow-sm` 级别投影） |
| 次按钮 | `.t-btn--ghost`（白底 + `--border` 描边 + 次文字色） |
| 徽标 | `.t-badge`（`--accent-light` 底 + `--accent-hover` 字） |
| 卡片 | `.t-card`（白底 + `--border-soft` + `--r-lg` + `--shadow-sm`） |
| 输入框 | 默认 `--bg-secondary` 底，聚焦改白底 + `0 0 0 3px var(--accent-light)` 光晕 |
| 浮层 | 白底 + `--border-soft` + `--r-lg` + `--shadow-md`，出现动效 ≤160ms |
| 悬停 | 只改背景/描边，不做位移（避免抖动） |

**交互安全区**：任何 hover 触发的浮层，指针离开触发源后要保留 ≥14px 的容错区，
避免「鼠标在角标和浮层之间移动时浮层闪掉」。实现参考 `apps/rag/static/rag/js/ask.js` 的 `POP_PAD`。

---

## 11. 接入方式

```html
{% load static %}
<link rel="stylesheet" href="{% static 'css/theme.css' %}">      <!-- 必须在前 -->
<link rel="stylesheet" href="{% static '你的app/css/xxx.css' %}">
```

在页面自己的样式里**不要写死颜色**，一律 `var(--xxx)`。
